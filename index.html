How to play

Place all the cats so every row, column and color has exactly one, and no cats touch.

  1. Rule 1One cat in each colorEvery color needs exactly one cat.
  2. Rule 2One cat per row and columnA cat takes its whole row and column. No sharing!
  3. Rule 3Cats don’t touchNot even corner to corner.
  4. Rule 4Look after your heartsA wrong cat costs a heart, so think before you tap.

🐾 Tip: switch to Paw mode (or press and hold a square) to mark spots where a cat can’t go.
